# Smart Employee Attendance System

An intelligent system for employee check-in/out using computer vision and OCR.

## Features
- Card detection with Template Matching
- OCR extraction with Tesseract
- Automatic attendance logging
- Excel report generation
- Live camera support

```bash
git clone https://github.com/yourusername/personnel-attendance-system.git
cd personnel-attendance-system
pip install -r requirements.txt
